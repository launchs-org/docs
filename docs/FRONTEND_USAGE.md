# Launchs 使い方ガイド

## Launchs とは

Launchs は、GitHub に置いたアプリのコードをかんたんにインターネット上へ公開・管理できるサービスです。
「プロジェクト」という単位でアプリをまとめ、その中に「コンテナ」を追加することでアプリが起動します。

---

## ログイン

Launchs を利用するには AuthBase でのログインが必要です。ログイン後、自動的にアプリ画面へ移動します。

---

## はじめて使う方へ — チュートリアル

左メニュー下部の **「チュートリアル」** をクリックすると、画面上で操作箇所がハイライトされながらひと通りの使い方を体験できます。途中でブラウザを閉じても、次回開いたときに続きから再開できます。

---

## 1. プロジェクトを作成する

ログイン直後は「プロジェクト」画面が表示されます。プロジェクトはアプリをまとめる入れ物です。

![プロジェクト一覧（空の状態）](docs/projects-empty.png)

まだプロジェクトがない場合は上のような空の画面が表示されます。右上の **「+ 新規プロジェクト」** をクリックしてください。

![プロジェクト作成ダイアログ](docs/projects-create.png)

ダイアログが開いたら **プロジェクト名** を入力し、**「プロジェクトを作成」** をクリックします。
プロジェクト名は **英小文字・数字・ハイフンのみ** 使用できます（例: `my-app`、`web-service`）。

![プロジェクト一覧](docs/projects-list.png)

作成するとカードが表示されます。右上に **「稼働中」** と表示されたらクリックして中に入れます。
作成直後は「準備中」と表示されることがありますが、しばらく待つと自動的に「稼働中」に変わります。

> **プロジェクトを削除するには**
> カードにマウスを乗せると右上に **「…」** が表示されます。クリックして「プロジェクトを削除」を選択してください。削除は取り消しできません。

---

## 2. コンテナを追加する（アプリをデプロイする）

プロジェクトカードをクリックすると、プロジェクト詳細画面が開きます。

![プロジェクト詳細（コンテナなし）](docs/project-detail.png)

コンテナがまだない状態です。右上の **「+ コンテナを追加」** をクリックしてください。

![新規デプロイダイアログ](docs/new-container.png)

ダイアログが開くので、以下の項目を入力します。

| 項目 | 説明 |
|---|---|
| **コンテナ名** | このアプリの名前（例: `my-app`） |
| **GitHub Repository URL** | デプロイしたいリポジトリの URL |
| **ブランチ** | URL を入力すると自動で選択肢が表示されます |
| **ディレクトリ** | ビルド対象のフォルダ。通常は `.`（ルート）のままで OK |

入力したら **「デプロイを開始する」** をクリックします。

---

## 3. ビルドの進行を確認する

![ビルド中の画面](docs/container-building.png)

デプロイを開始するとフロー図にコンテナカードが表示され、右上に **「ビルド中」** バッジが出ます。
左下の凡例でコンテナの状態（実行中・準備中・失敗・デプロイ中 など）を確認できます。

カードをクリックすると右側にサイドパネルが開きます。**「ビルド」タブ** をクリックするとビルドの進行ログをリアルタイムで確認できます。

![ビルドログ](docs/container-buildlog.png)

ログが流れている間はビルドが進行中です。完了まで初回は数分かかることがあります。

---

## 4. アプリの起動を確認する

![実行中の画面](docs/container-running.png)

ビルドが完了するとコンテナが起動し、カードのバッジが **「実行中」** に変わります。
サイドパネルの **「実行」タブ** ではアプリが出力するログをリアルタイムで確認できます。
エラーメッセージが出ていないか、起動メッセージが表示されているかをここでチェックしてください。

サイドパネルのタブでできる主な操作は以下の通りです。

| タブ | できること |
|---|---|
| **概要** | リポジトリ・ブランチの確認、Pod の起動台数の変更（1〜5台） |
| **履歴** | 過去のビルド一覧と成否の確認 |
| **ビルド** | ビルドログのリアルタイム確認 |
| **実行** | 実行中アプリのログ確認 |
| **ネット** | インターネット公開 URL の発行・設定 |
| **Vol** | データ保存用ボリュームの管理 |
| **ENV** | 環境変数（設定値・シークレット）の管理 |
| **削除** | コンテナの削除 |

---

## 5. アプリをインターネットに公開する

サイドパネルの **「ネット」タブ** を開きます。

![ネット（Ingress）設定画面](docs/container-ingress.png)

**① 内部ポート設定をオンにする**

右上のトグルをクリックしてオンにします。アプリが使っているポート番号（PORT と TARGET）を入力して **「適用」** をクリックしてください。

**② 外部公開を有効化する**

「外部公開 (Ingress)」セクションの **「外部公開を有効化」** ボタンをクリックします。
しばらくすると **DEFAULT DOMAIN** に URL が発行されます。リンクアイコンをクリックしてアプリにアクセスできます。

**独自ドメインを使いたい場合**

「CUSTOM DOMAIN」欄に独自ドメインを入力し、右のトグルをオンにして **「保存」** をクリックしてください。

> 外部公開を停止したい場合は **「停止」** ボタンをクリックしてください。

---

## 6. コンテナを削除する

サイドパネルの **「削除」タブ** を開きます。

![コンテナ削除画面](docs/container-delete.png)

誤操作防止のため、入力欄に **コンテナ名を正確に入力** する必要があります。
入力すると **「コンテナを完全に削除する」** ボタンが有効になります。クリックして確認ダイアログを承認すると削除されます。

> **この操作は取り消しできません。** 関連するデータもすべて削除されます。

---

## よくある操作

### GitHub のコードを更新してアプリに反映したい

サイドパネル上部の **「再ビルド」** ボタンをクリックします。最新のコードが取得されてビルド・デプロイが実行されます。

### 環境変数を変更して反映したい

1. **「ENV」タブ** で変数を編集して「変更を保存」
2. サイドパネル上部の **「再デプロイ」** ボタンをクリック

### アプリが起動しない・エラーが出ている

- **「ビルド」タブ** でビルドログにエラーが出ていないか確認する
- **「実行」タブ** でアプリのエラーログを確認する
- **「概要」タブ** で Pod のステータスが「Ready」になっているか確認する
