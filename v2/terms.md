# launchs(v2)利用規約

最終更新: 2026-11-26

この規約は、launchs(以下「本サービス」)の利用条件です。

**サインアップ(アカウントの登録)、または、ログインをした時点で、この規約(と、[プライバシーポリシー](privacy.md))の全ての内容に、同意したものとみなします。** 本サービスの API やトークンを使う場合も、同じです。同意できない場合は、サインアップも、ログインも、しないでください。

## 1. 本サービスについて

- 本サービスは、個人が趣味・開発の一環として運営している、アプリをデプロイするための実験的なサービスです。
- 運営者(以下「運営者」)は、個人です。会社や団体が提供する商用のサービスではありません。

## 2. 自己責任での利用

- **本サービスは、全て自己責任で使ってください。**
- 本サービスは「現状のまま」で提供します。動作、正確さ、安全性、特定の目的への適合性などについて、運営者は、何も保証しません。
- 本サービスの利用、または利用できなかったことで生じた損害(データの消失・漏えい、収益の損失、業務の停止、第三者との紛争などを含む)について、運営者は、**一切の責任を負いません**。ただし、法律上、責任を免れることができない場合は、その範囲で責任を負います。

## 3. 可用性と、データについて

- 本サービスの**稼働(可用性)は、保証しません**。予告なく、停止、遅延、障害、不具合が起きることがあります。
- **データの保存と、バックアップは、保証しません**。データは、いつでも消えることがあります。大切なデータは、**必ず、自分で、別の場所にバックアップしてください**。
- 重要な用途(事業の中心、人命や財産に関わるもの、個人情報や機密情報の大量の保管など)には、使わないでください。

## 4. サービスの変更、停止、終了

- 運営者は、**いつでも、予告なく、理由を示さずに**、本サービスの全部または一部を、変更、停止、終了できます。
- 運営者は、いつでも、アカウントの停止、デプロイやデータの削除、アクセスの制限ができます。
- これによって生じた損害について、運営者は、責任を負いません。

## 5. 禁止すること

次のことを、してはいけません。

- 法律や公序良俗に反すること、他人の権利(著作権、プライバシーなど)を侵すこと。
- 他人への攻撃(DoS、不正アクセス、スパム、フィッシング、マルウェアの配布など)や、そのための基盤として使うこと。
- 本サービスや、同じ基盤を使う他の利用者の、運用を妨げること(過剰な負荷、他のプロジェクトへの侵入の試みなど)。
- 暗号資産のマイニングなど、計算資源を、主な目的として使うこと。
- アカウントや、API トークンなどの認証情報を、他人に渡すこと。
- 運営者が、不適切だと判断すること。

これらに当てはまる場合、運営者は、予告なく、停止や削除ができます。

## 6. 利用者のコンテンツ

- デプロイしたアプリ、設定、データなどの権利は、利用者のものです。その内容と、公開した結果の責任は、利用者が負います。
- 運営者は、サービスを運営するために必要な範囲(保存、実行、表示、バックアップ、調査など)で、これらを扱います。

## 7. 規約の変更

運営者は、この規約を、いつでも変更できます。変更した後に、本サービスを使い続けた場合は、変更に同意したものとします。最新の規約は、このページに載せます。

## 8. 準拠法

この規約は、日本法に従います。
