# launchs(v2)プライバシーポリシー

最終更新: 2026-11-26

launchs(以下「本サービス」)で扱う情報と、その扱い方です。

## 1. 基本の方針

サインアップ、または、ログインをした時点で、このポリシーと、[利用規約](terms.md)に、同意したものとみなします。

**本サービスで手に入れた情報は、他の人に見せません。** 次の「例外」を除いて、第三者に、提供も、公開もしません。

## 2. 扱う情報

| 情報 | 何のために |
|---|---|
| アカウントの情報(ユーザー名、メールアドレスなど。パスワードは、元に戻せない形(ハッシュ)で保存) | ログインと、アカウントの管理 |
| ログインの履歴(日時、IP アドレス、ブラウザの情報) | 不正の検知と、安全のため |
| プロジェクトの情報(デプロイ、設定、環境変数、ボリューム、ドメインなど) | サービスの提供 |
| デプロイしたアプリの出力ログ | 利用者への表示 |
| アプリへのアクセスの記録(日時、パス(クエリを含む)、アクセス元の IP、ステータスなど) | 利用者への表示と、アクセスの集計 |
| 外部の送り先の情報(webhook の URL、Google Drive の接続の鍵) | 利用者が設定した、アクセスログの転送。**Google の鍵などの秘密は、暗号化して保存します** |

- アクセスの記録は、**既定で 24 時間だけ**、保存します(ingress ごとに、行数の上限もあります)。
- Google Drive につなぐときの権限は、**launchs が作ったファイルとフォルダだけ**に限っています(利用者の、他のファイルは、読めません)。

## 3. 第三者に出す場合(例外)

- **法令に基づく場合**(裁判所や捜査機関からの、法的な手続きによる要請など)。
- **人の生命、身体、財産を守るために、必要な場合**。
- **サービスの運営に必要な、外部のサービス**: Cloudflare(通信の中継と、ボット対策の Turnstile)、GitHub(コンテナイメージの保管など)。必要な範囲で、情報が、これらを通ります。
- **利用者が、自分で設定した送り先**: webhook や Google Drive など、利用者が選んだ送り先には、利用者のアクセスログが、送られます。
- 利用者が、**自分で公開した**もの(公開した ingress の内容など)は、誰でも見られます。

## 4. 運営者が見ることがある場合

運営者は、障害の調査、不正の対応、サービスの保守のために、必要な範囲で、保存された情報を、見ることがあります。**それ以外の目的では、見ません**。

## 5. 安全のための取り組みと、その限界

- 通信は、暗号化(HTTPS)します。秘密は、暗号化して保存します。
- ただし、**完全な安全は、保証できません**。情報が漏れたり、消えたりしても、運営者は、[利用規約](terms.md)のとおり、責任を負いません。
- 重要な情報や、個人情報は、本サービスに、置かないでください。
